# Google Sheets Contact Cleanup

**Who it is for:** non-technical users who keep a contacts list in Google Sheets.

**What it does**

- Works from a single `Name` column as well as separate first/last columns.
- Lower-cases emails so duplicates with different casing collapse together.
- Converts phone numbers written in any style to E.164.
- Removes duplicate rows.
- Warns about contacts with no email (usually fine, but worth checking).

**How to use it**

In Google Sheets choose **File > Download > Comma-separated values (.csv)**,
then upload that file here.
