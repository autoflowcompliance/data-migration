# AI Readiness Audit

**Who it is for:** anyone about to start an AI, analytics or CRM project who
needs to know whether their data is good enough to begin.

**What it does**

- Maps your export onto a neutral record shape without forcing a CRM schema.
- Scores the file on five dimensions: completeness, uniqueness, validity,
  consistency and timeliness.
- Flags missing emails and missing dates, the two problems that most often
  block an AI project.
- Produces a one-number quality score you can put in a project brief.

**How to read the result**

- **90-100** — ready to use.
- **70-89** — usable, but fix the flagged columns first.
- **Below 70** — fix completeness before spending money on modelling.
