# Data Migration Tool - Hugging Face Spaces Deployment

Professional CRM data cleaning and migration tool deployed on Hugging Face Spaces.

## Features
- 🔒 Zero data storage - files processed in memory only
- ⚡ 60-second processing time
- 🎯 95%+ quality score guarantee
- 📋 First 500 rows free demo
- 🏷️ Custom branding support

## Supported CRMs
- HubSpot
- Salesforce
- Pipedrive

## Usage
1. Upload your CRM export CSV
2. Select your target CRM
3. Configure processing options
4. Click "Process Data Migration"
5. Download clean data and QA report

## Architecture
- **Frontend**: Gradio interface
- **Backend**: Professional data pipeline
- **Hosting**: Hugging Face Spaces (Gradio SDK)
